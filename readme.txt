Custom app manager plugin with GitHub-based auto-updates.


== Description ==


Kareem App Manager is a custom WordPress plugin that provides app management functionality. It automatically checks for updates from the GitHub repository and notifies you when new versions are available.


**Features:**


* Automatic update checks via GitHub Releases
* Simple admin dashboard interface
* Easy version management


== Installation ==


1. Download the latest release ZIP from the GitHub Releases page.
2. In WordPress, go to Plugins > Add New > Upload Plugin.
3. Upload the ZIP file and activate the plugin.
